# TextForge AI — GitHub Pages

A complete static browser-based 3D text/logo maker starter.

## Features
- Responsive premium UI
- Text editor
- Font selection
- Size/spacing/color controls
- X/Y/Z rotation
- Neon, gold, chrome, fire, ice, cyber and shadow presets
- Templates
- Undo/redo
- Duplicate/reset
- Transparent canvas
- SVG export
- PNG export
- AI prompt interface
- SEO title/description/canonical
- Open Graph
- WebApplication JSON-LD
- robots.txt
- sitemap.xml
- No server required

## GitHub Pages
1. Create a repository.
2. Upload `index.html`, `robots.txt`, and `sitemap.xml`.
3. Settings → Pages → Deploy from branch → main → root.
4. Replace `YOUR-USERNAME` in `index.html` and `sitemap.xml` with your actual GitHub username.

## Real AI
GitHub Pages cannot safely store private API keys. The included AI modal is a frontend-ready interface. For real AI image generation, connect a secure serverless endpoint such as Cloudflare Workers, Vercel Functions, Netlify Functions, or another backend.
